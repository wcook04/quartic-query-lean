# Writing-method findings

Nine proposed changes to the supplied methods. Several rules are already sound; those findings ask for a meaningful acceptance check rather than a contradictory new rule. No skill has been changed.

## SX-M01: Competing obligations; priority rule under-specified.

`skills/record-to-expository/SKILL.md`, line 72:

> open with about a page that states the

The orientation rule asks the opening to carry a formal theorem, a mechanism, history, an example map, audience and outcomes, but gives no priority when those obligations exceed one page. Here the overview spans roughly 1.76 page-equivalents and exact constants precede the key mechanism.

**Proposed rule change.** Rank first-page obligations by the modeled reader's next decision and validate the rendered opening. Preserve exact theorem scope, but allow supporting quantitative provenance and detailed example maps to move after the main mechanism.

**Instance evidence:** SX-002, Exposition Overview and physical PDF pp.1–2.

## SX-M02: Conflicting size and fidelity instructions.

`skills/record-to-expository/SKILL.md`, line 84:

> collect the formal correspondences in a closing half-page.

A fixed half-page budget competes with the simultaneous requirement to explain every same/stronger/weaker relationship. Here that produces a dense closing audit with multiple distinct reader tasks rather than a usable first check.

**Proposed rule change.** Budget the closing section by a specified reader action. Keep a minimal required statement check and route complete fidelity details to a clearly marked audit destination; never meet a page target by compressing away a meaningful qualification.

**Instance evidence:** SX-033, Exposition §7; expert companion Appendix A.

## SX-M03: Existing rule missed; enforcement criterion needed.

`skills/record-to-expository/SKILL.md`, line 51:

> A level such as “graduate” or a list of defined terms is
> not this prerequisite ladder.

The rule is already correct, but the declared audience still promises only query-model knowledge while the text uses coherent conditional sampling and adaptive posterior arguments. The method needs a concrete acceptance check for its own prerequisite requirement.

**Proposed rule change.** Before accepting the exposition, record for each first consequential use whether the operation is supplied by a named prerequisite, explicitly taught here, or accepted as a stated input. Report uncovered operations as scope mismatches.

**Instance evidence:** SX-001, Exposition Overview and §§4–5.

## SX-M04: Existing rule missed; worked-example and independent-task distinction needs a gate.

`skills/record-to-expository/SKILL.md`, line 190:

> Give a justified answer separately from the question, or mark it open.

The exposition contains fully worked changed cases but no separately posed student task. This can satisfy a surface count of examples while leaving the declared learning outcomes untested.

**Proposed rule change.** Require at least one task that reaches the promised key inference without its answer immediately supplied. Record its location and answer location, and explicitly leave actual reader performance unassessed when no reader participated.

**Instance evidence:** SX-003, Current exposition Overview promises hand execution and rederivation.

## SX-M05: Cross-route consistency rule incomplete.

`skills/README.md`, line 126:

> opens with a reading guide that separates the required
> proof path from optional routes and evidence,

The new guide and the older local dependency permission disagree about whether the independent Forrelation hardness proof is required before the construction. A guide can be present and individually plausible while failing to describe a consistent journey.

**Proposed rule change.** Name the objective of each route and compare global required/optional labels with local skip permissions after every navigation revision. Distinguish proving all imported ingredients from learning the downstream mechanism.

**Instance evidence:** SX-042, Record Reading guide and §1.1 Dependencies and proof recovery.

## SX-M06: Observable teaching test under-specified, not a missing mathematical proof.

`skills/record-to-expository/SKILL.md`, line 129:

> the next required
>    conclusion and the local argument joining them.

The instruction allows a general derivation to pass as visible even when the recurring example has not been carried through that derivation. The current sampler has all its formal pieces but leaves the example-to-state-to-conditional-pivot connection to the teacher.

**Proposed rule change.** For the one decisive new operation, require a short reconstruction check that starts from the example's established data and ends at the next claimed output. If a worked example is unsuitable, state the imported interface and the concrete task the reader can do with it.

**Instance evidence:** SX-019, Exposition §4 weight table, fractional update, sampler product formula and amplification.

## SX-M07: Cross-document extension of an existing good rule.

`skills/record-to-expository/SKILL.md`, line 121:

> Reuse the example while it reveals something;

The method already requires an admissible small example and warns against forcing one through every section. What is still missing is an explicit identity check at a link into a different example: Figure 4 changes the data law, while the record simulator changes the partial function, indexing and cap.

**Proposed rule change.** At a cross-document worked-example link, record what stays fixed and what changes: object, input law, index convention, parameters, claimed invariant and return point. Permit a better different example, but do not let it arrive as an unexplained continuation.

**Instance evidence:** SX-012, SX-024, SX-031.

## SX-M08: Propagation check missing from feedback integration.

`skills/README.md`, line 93:

> Repair the paper first.

A local repair can leave an earlier summary teaching the old inference. Here the detailed cell-visit argument correctly allows guessing, while the opening still sounds as though visiting the cell requires paying L queries.

**Proposed rule change.** When a correction changes the scope or logic of an explanation, check every abstract, opening, figure caption and reading guide that summarizes it. Record where the correction was propagated; a repaired proof paragraph alone is not the completion condition.

**Instance evidence:** SX-004, previous_round/dispositions/exposition.json: CM-003 and ES-004.

## SX-M09: Comparison-target identity and maintenance rule.

`skills/long-to-short/SKILL.md`, line 182:

> formal statement is the same as the printed claim, stronger, or weaker,

The correct instruction to state a formal/informal relation can be implemented with a label whose reason belongs to an older version of the printed claim. The amplifier table cites the returned state as extra even though the current Lemma 2 already includes it.

**Proposed rule change.** For every relation label, identify the exact current printed comparator and the concrete added, removed or altered clause. Recheck that pairing after either side is edited. Keep execution status separate, and validate reproduction comments against their linked editions.

**Instance evidence:** SX-040, SX-041.
