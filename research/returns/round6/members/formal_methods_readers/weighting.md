# Weighting for the formal-methods reader panel

## Measurement boundary and recommendation

The supplied expert companion and exposition each contain **14 PDF pages**. The supplied reasoning-record PDF contains **125 pages**. `SOURCE_STATUS.json` explicitly says that the current record Markdown differs from the edition underlying that PDF; it records 694 changed lines. No current-record PDF was generated for this review. The record figures below are therefore **allocation estimates using the older supplied render**, accompanied by current-text token shares. They are not a claimed pagination of the current record.

Page equivalents were estimated from the position of each top-level heading to the next, using a 700-point content band. They include figures, tables, within-section space and page breaks; the last section includes final-page whitespace. Percentages have a 14-page or 125-page denominator. This is an editorial allocation measure, not a precisely measured occupied area. Current-record text share removes passage comments, HTML anchors and link destinations, retains mathematical notation, and counts whitespace-separated tokens (50,867 in total). The latter helps detect changed scope but does not predict typography, especially the catalogue's many short entries.

The suggested shares are a panel judgment for these particular documents. They sum to 100% within each document; keeping the same total page budget is only a normalization. They do **not** call for padding proofs or deleting the recoverable record. Time saved from repeated framing, historical bookkeeping and sparse catalogue layout should make existing semantic bridges, counterexamples and proof interfaces easier to inspect. The short expert paper should remain a mathematics paper; the exposition should remain a teaching route.
