## The ten changes that matter most

1. **Honor the specified audience.** Teach one query, the measurement rule and the required probability conventions at first use. Naming advanced prerequisites did not supply them.

2. **Correct Question 4.** Fixed $k=4$ proves $\alpha_{\rm tot}\ge3.5$ by excluding every smaller exponent. $k=5$ excludes the endpoint power itself. Match question and answer.

3. **Repair the example relationship.** The exposition's three raw strings differ from the record/checker's board and have different decoder probabilities. Scope the script claim or align the examples.

4. **Repair the return directions.** The record still names the companion's old section numbers. Send the exposition's simulator-example link to the actual trace.

5. **Preserve probability scope in summaries.** Use a transcript prefix for the next-query estimate; distinguish a fixed cell-query event from eventual discovery over $G$ attempts.

6. **Put the sampler execution earlier.** Keep the completed deterministic stage, then use the record's existing fractional row to teach unequal weights and normalization.

7. **Explain amplification's invariant.** The good vector includes every retained register. Teach why successful label proportions survive; move most trial constants to the record while retaining the all-input cap.

8. **Complete local verification.** Show a gate test reading actual input versus transcript wires, then explain how a test label controls a reversible check. The full circuit is not recomputed for every candidate.

9. **Make the lower-bound reduction executable.** Use the existing simulator trace to teach the cap, output label and event inclusion. Let one question test that promised understanding.

10. **Rebalance the companion.** Give exact sampling and direct-product factorization more space; demote loose constants and optional refinements. Fix the separation table's equality-shaped heading.
