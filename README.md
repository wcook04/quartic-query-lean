# quartic-query-lean

A Lean corpus for the nearly quartic separation between randomized and quantum
query complexity, built from
[OpenAI's preprint](https://github.com/openai/math/blob/main/preprints/A-Nearly-Quartic-Separation-Between-Randomized-and-Quantum-Query-Complexity-October-5-2026/quartic-query-separation.pdf).

The repository is being set up. It will index every statement in the paper, its
references, related Lean work and the status of each check.

Nothing here is formally verified yet. The preprint and its mathematics are
OpenAI's.
